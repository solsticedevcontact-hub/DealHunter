# 🎯 صايد الفرصة (DealHunter) v3

أداة سطح مكتب بتصطادلك **الألعاب المجانية والخصومات الحقيقية** من أكتر من 10 متاجر موثوقة، وتفضل في الخلفية جنب الساعة وتبلّغك (إشعار ويندوز / Discord / Telegram).

## الجديد في v3
- **واجهة جديدة بالكامل** (داكنة، RTL، كروت، بانر للمجاني، فلاتر وبحث). بتتفتح في نافذة تطبيق مستقلة (Edge/Chrome) وبتقفل تماماً لما تقفلها → **استهلاك شبه صفر** وأنت مش بتستعملها.
- **مصادر أكتر (APIs مجانية من غير مفاتيح):**
  | المصدر | بيجيب إيه |
  |---|---|
  | Epic Games (الرسمي) | المجاني دلوقتي + الجاي + عداد تنازلي |
  | CheapShark | خصومات Steam / GOG / Epic / Humble / Fanatical / GreenManGaming / Gamesplanet / GamersGate / EA / Ubisoft / Blizzard (بيتحدد تلقائي من قايمة المتاجر الموثوقة) + أقل سعر تاريخي |
  | GamerPower | ألعاب مجانية من Epic / Steam / GOG / itch.io / Prime Gaming / Ubisoft… |
  | Steam Specials | وقت انتهاء الخصم الحقيقي |
- **ربط حساب Steam بتسجيل الدخول الرسمي (OpenID)**: الباسورد بيتكتب في صفحة Steam بس. بعدها بيستورد الأمنيات ويقرا مكتبتك (من غير API Key لو البروفايل Public) ويخفي اللي معاك + مزامنة تلقائية كل 24 ساعة.
- **قنوات إشعار:** إشعار ويندوز + Discord Webhook + Telegram Bot (كل واحدة بزرار تجربة) + **ساعات هدوء** (الإشعارات بتتأجّل مش بتضيع).
- **توفير حقيقي في الموارد:** جدولة مستقلة لكل مصدر، ETag + gzip (لو مفيش تغيير مفيش تحميل)، أمنيات بطلب واحد لكل 25 لعبة، backoff تلقائي لو مصدر وقع، وضع 🍃 توفير / ⚖️ متوازن / 🚀 سريع، والواجهة بتوقف polling وهي مصغّرة.
- **أمان:** السيرفر المحلي على 127.0.0.1 بس، بتوكن عشوائي لكل تشغيل + فحص Host، والـ Webhooks/التوكنز مبتتبعتش للواجهة تاني.

## حدود لازم تعرفها
- **Epic و GOG مفيهمش ربط حساب رسمي آمن** (الحلول غير الرسمية بتطلب باسوردك وممكن تعرّض الحساب للحظر) فمش مدعومين. استخدم الأمنيات وزرار "خدتها".
- "احصل عليها" بيفتح صفحة اللعبة وإنت اللي بتضغط Claim — البرنامج مبيعملش Claim آلي.
- مفيش Scraping لمواقع تانية (هش ومخالف لشروطهم)؛ التغطية عن طريق الـ APIs اللي فوق.

## تشغيل من الكود
```bash
pip install -r requirements.txt
python main.py
python -m unittest discover -s tests      # اختبارات (36)
python tools/ui_check.py                  # فحص الواجهة بمتصفح حقيقي (محتاج: pip install playwright)
```

## بناء exe
على ويندوز: `build.bat` ← `dist\DealHunter.exe`، أو من GitHub: **Actions ← Build & Release**.

## لو حاجة مشتغلتش
الإعدادات ← **🩺 فحص الاتصال** (بيقولك أنهي مصدر مش بيرد) و **📄 ملف السجل**.
